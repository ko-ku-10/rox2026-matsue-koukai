# 機構名 / Component Name

このフォルダは、新しい機構の設計データを公開するためのテンプレートです。フォルダをコピーして、機構名に合わせて名前を変更してから使ってください。

## この機構について

- 目的:
- 担当:
- 最終更新:
- 公開範囲: 公開可 / チーム内のみ / 大会後に公開

## 入れるファイルの例

| ファイル | 内容 |
| --- | --- |
| `preview.webp` | 機構のプレビュー画像（推奨） |
| `component.step` | STEP形式の3D CAD |
| `component.stl` | STL形式の3D CAD |
| `drawing.pdf` | 組立図・加工図・配線図など |
| `BOM.csv` | 部品表（必要な場合） |

## 注意

- 公開してはいけない個人情報、ライセンス上公開できないデータ、第三者の設計データは入れないでください。
- 大容量の元CADデータは、GitHubのファイルサイズ制限に注意してください。必要に応じてGit LFSやReleaseの添付を検討します。
- このREADMEの内容を機構の説明として更新すると、後から見返す人にも伝わりやすくなります。
